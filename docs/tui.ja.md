# cappy tui

[English](./tui.md) | 日本語

`cappy tui` は、プロファイル・操作・録音するアプリを全画面で選び、Enter で録音を始めます。

```
 cappy — 設定と録音するアプリを選んでください

   プロファイル    default  (Gemini, ja-JP)
   操作            録音 → 文字起こし → 要約
   マイク          オン
   自動停止        しない（Ctrl-C で停止）
   セッション名    weekly-sync

   音声を使うアプリ（● 出力中。自動で更新します）
 ▶ ● zoom.us                us.zoom.xos
     Google Chrome          com.google.Chrome  (3 プロセス)
     assistantd             com.apple.assistantd
     システム全体の音声（cappy を除く）  --system

 ↑↓ 移動  Enter 録音を開始  r 更新  q 終了
```

- 上の欄は ↑↓ で行を選び、Enter で選択肢のウィンドウを開いて ↑↓ と Enter で選びます（Esc で取り消し、✓ が今の値）。←→ で前後の値に直接切り替えることもできます。セッション名は、その行で Enter を押すと編集が始まり、Enter で確定、Esc で取り消します。
- 操作は「録音のみ」「録音 → 文字起こし」「録音 → 文字起こし → 要約」「リアルタイム文字起こし」「リアルタイム文字起こし → 要約」から選びます。プロファイルの `transcribe.provider` / `summary.provider` が `none` なら、使えないものは出しません。初期値は `summary.auto` が true なら要約まで、それ以外は文字起こしまでです。
- 下の欄は音声を使うアプリの一覧です。出力中のもの、`/Applications` などのアプリ、システムのデーモン（薄く表示）の順に並べ、1.5 秒ごとに更新します。`com.google.Chrome.helper` のようなヘルパーは親の bundle ID の行にまとめます（`--app` は前方一致なのでヘルパーも録音されます）。
- アプリを選んで Enter を押すと、その設定で録音を始めます。録音・変換・文字起こし・要約の間も全画面のままで、選んだ内容、レベルメーターや進み具合、メッセージ（リアルタイム文字起こしの字幕を含む）を表示します。最初に同じ内容の `cappy record ...` を表示します。
- 録音中のキーは `record` と同じです（Space でマイクのミュート / 解除、Enter でマーカー。先に文字を入力するとラベル付き）。
- `--profile` で初めに選ぶプロファイルを指定できます。選ぶ画面では q・Esc・Ctrl-C で何もせずに終了します。
- 端末で「あいまい幅の文字を全角で表示」を有効にしていて表示が崩れる場合は、`--ascii`（または `CAPPY_TUI_ASCII=1`）で記号（`▶ ● ─ │ → …` など）を ASCII で描きます。

### 過去の録音

Tab で「録音」と「過去の録音」のページを切り替えます。過去の録音のページには、すべてのプロファイルの保存先（`output_dir`）にあるセッションを新しい順に並べ、日時・長さ・文字起こしと要約の有無・名前と録音対象を表示します。下の欄には選んだセッションのフォルダ、トラックの長さ、文字起こしと要約の状態、マーカーを出します。

Enter で操作のメニューを開きます。よく使う操作は一覧で直接キーを押しても実行できます。

| キー | 操作 |
| --- | --- |
| `t` | 文字起こし（`transcript.md`）を表示 |
| `l` | リアルタイム文字起こし（`live-transcript.md`）を表示 |
| `s` | 要約（`summary.md`）を表示 |
| メニューのみ | 要約を作成（文字起こし済みで、まだ要約していないセッションのみ） |
| `p` | 相手と自分を合わせて再生（2 本の送信用ファイルをミックスして、既定の再生アプリで開く） |
| メニューのみ | 相手の音声 / 自分の音声を開く（原本の CAF。なければ送信用ファイル） |
| `f` | フォルダを Finder で開く |
| `d` | 削除（セッションのフォルダをゴミ箱に移動） |
| `r` | 一覧を読み直す |

- 表示はスクロールできます（↑↓・Space / b でページ送り・g / G で先頭 / 末尾、q で一覧に戻る）。
- 音声は `open` で既定のアプリ（通常は QuickTime Player）に渡します。ミックスは一時ディレクトリ（`$TMPDIR/cappy-playback/`）に作り、次からはそれを使います。`--mix` で文字起こししたセッションは、そのとき作ったミックスを開きます。
- ファイルがない操作（文字起こし前のセッションの文字起こしなど）はメニューに出しません。
- 要約の作成は、録音したときのプロファイルで `cappy summarize` と同じことを行います（`transcript.json`、なければ `live-transcript.json` から）。進み具合を全画面に表示し、終わると一覧に戻ります。Ctrl-C で中断して一覧に戻ります。
- 削除は確認してから行います（初めは「キャンセル」を選んだ状態。「ゴミ箱に移動する」を選んで Enter か `y` で実行）。完全には消さずにゴミ箱へ移すので、Finder から元に戻せます。再生用に作ったミックスの一時ファイルも消します。別のターミナルで録音中のセッションは削除できません。Cloud Storage や S3 に残っている音声は消しません（通常は文字起こしの後に削除済みです）。

### 終了と中断

| いつ | 方法 | どうなるか |
| --- | --- | --- |
| 録音中 | Ctrl-C | 録音を停止して保存し、選んだ変換・文字起こし・要約に進む |
| 録音中 | 自動停止の時間になる、Mac がスリープする、別のターミナルから `kill`（SIGTERM） | Ctrl-C と同じ |
| 録音の停止処理中 | Ctrl-C | 送信用ファイルへの変換を省いて終える（後で `cappy recover`） |
| 変換中 | Ctrl-C | 中断する。録音（CAF）は保存済みで、`cappy recover` で作り直せる |
| 文字起こし中 | Ctrl-C | 中断する。`cappy transcribe <dir>` で続きから再開できる |
| 要約中 | Ctrl-C | 中断する。`cappy summarize <dir>` で作り直せる |
| 録音を始める前（権限の確認など） | Ctrl-C | 何も残さずに中止する |
| アプリを選ぶ画面 | q・Esc・Ctrl-C | `cappy tui` を終える |

録音・文字起こし・要約がすべて終わると（エラーで終わった場合も）、アプリを選ぶ画面に戻ります。上に結果（保存先やエラー）を表示し、`l` で前回のログを見直せます。設定はそのまま残るので、続けて次の録音を始められます。変換・文字起こし・要約を Ctrl-C で中断したときは、選ぶ画面には戻らずに `cappy tui` を終えます。

`cappy tui` を終えると、表示していたメッセージ（すべての録音の分）を通常の端末に書き出すので、保存先のパスや再開のコマンドを後から確認できます。
