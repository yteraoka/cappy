# gcappy（メニューバー版）

[English](./gcappy.md) | 日本語

gcappy は cappy の GUI 版です。メニューバーのアイコンから、会議アプリを選んで録音を始め、停止・マイクのミュート・スクリーンショットを操作できます。録音の後の文字起こしと要約も、選んだ設定のとおりに続けて行います。

## インストール

```bash
brew install yteraoka/cask/gcappy
gcappy        # メニューバーに常駐させる（open で gcappy.app を起動する）
```

- `gcappy.app` は `$(brew --prefix gcappy)/gcappy.app` に入ります。cappy 本体（`gcappy.app/Contents/MacOS/cappy`）を同梱しているため、CLI の cappy を別に入れる必要はありません（ターミナルでも使うなら `brew install yteraoka/cask/cappy`）。
- Spotlight や Launchpad から起動したい場合は `~/Applications` にリンクします。

  ```bash
  mkdir -p ~/Applications && ln -sf "$(brew --prefix gcappy)/gcappy.app" ~/Applications/gcappy.app
  ```

- ログイン時に自動で起動するには、メニューの「ログイン時に起動」を選びます。
- ソースからは `make app`（`dist/gcappy.app` を作る）、`make install-app`（`~/Applications` にコピー）です。

## 使い方

メニューバーの波形のアイコンをクリックするとメニューが開きます。

| メニュー | 内容 |
| --- | --- |
| （前回の対象）を録音 | 前回録音したアプリがいま音声プロセスとして見つかれば、すぐ録音を始めます（⌘R） |
| 録音を開始 ▸ | 音声プロセスの一覧（スピーカーのアイコンは出力中）から録音対象を選びます。最後の「システム全体の音声」は `--system` です |
| プロファイル ▸ | 設定ファイル（`~/.config/cappy/config.toml`）のプロファイル |
| 録音の後 ▸ | 録音のみ / 文字起こし / 文字起こし → 要約 / リアルタイム文字起こし（→ 要約）。`cappy tui` と同じ選択肢です |
| マイク ▸ | オン / ミュートで開始 / オフ（録音しない） |
| 自動停止 ▸ | 指定時間で録音を止めます（`--duration`） |
| 開始時にセッション名を尋ねる | 録音を始める前に、録音の告知の注意とセッション名の入力欄を表示します |
| 録音のフォルダを開く | プロファイルの `output_dir` |
| ツール ▸ | 設定ファイルを Finder で表示、ターミナルで `cappy init` / `cappy doctor` を実行、ログ、プライバシーとセキュリティの設定 |

録音中はアイコンが赤い録音マークと経過時間になり、メニューは次のようになります。

| メニュー | 内容 |
| --- | --- |
| 録音を停止（⌘.） | Ctrl-C と同じです。続けて送信用ファイルの作成と、選んだ文字起こし・要約を行います |
| マイクをミュート（⌘M） | `cappy mic toggle` と同じです。ミュート中はアイコンがマイクに斜線のマークになります |
| アプリのウインドウのスクリーンショット（⌘S） | `cappy shot` と同じです（画面収録の許可が必要） |
| セッションのフォルダを開く | 録音中のセッションディレクトリ |

録音を止めた後の処理中は砂時計のアイコンになります。終わると通知を出し、メニューに「前回の要約を開く」などが出ます。エラーで終わった場合は、cappy の出力の末尾をダイアログで表示します。

ターミナルの `cappy record` など、gcappy 以外で録音しているものも「ほかの cappy の録音」に表示し、ミュート・スクリーンショット・停止ができます。

## 仕組み

- gcappy は同梱の cappy を `cappy record --app <bundle ID> --profile <名前> ... --quiet` のように子プロセスで実行します。設定ファイル・セッションディレクトリ・`cappy transcribe` での再開など、CLI とまったく同じに扱えます。
- 録音中かどうか、マイクのミュートの状態は、`cappy mic` / `cappy shot` と同じ登録簿（一時ディレクトリの `cappy/record-<pid>.json`）で判断し、操作もシグナルで行います。
- cappy の出力は `~/Library/Logs/gcappy/record-<日時>.log` に保存します（30 日より前のものは起動時に消します）。録音のログ（`cappy.log`）はこれまでどおりセッションディレクトリにも残ります。
- Finder やログイン項目から起動したアプリには、シェルで設定した `PATH` や `AWS_PROFILE`、`GOOGLE_APPLICATION_CREDENTIALS` などが渡りません。gcappy は起動時にログインシェル（`$SHELL -l -i`）の環境変数を読み、cappy に渡します。
- 表示言語は macOS の優先言語に合わせます（`CAPPY_LANG` をシェルで設定していればそれを使います）。作るファイルの言語はこれまでどおりプロファイルの `language` で決まります。
- gcappy を終了すると、録音中なら停止を確認したうえで録音を止めます。文字起こしと要約はバックグラウンドで続きます（通知は出ません）。

## 権限

gcappy から録音する場合、「システムオーディオ録音」と「マイク」の許可は **gcappy** に対して求められます（ターミナルの cappy とは別に許可します）。

- 初回の録音で許可のダイアログが出ます。許可されていない場合、cappy は終了コード 2 で終わり、gcappy が設定を開くボタン付きのダイアログを出します。
- 設定の場所: システム設定 > プライバシーとセキュリティ > 画面収録とシステムオーディオ録音（「システムオーディオ録音のみ」）、および「マイク」
- スクリーンショットを使う場合は「画面とシステムオーディオ録音」の許可も必要です。
- Homebrew で配布している gcappy.app は ad-hoc 署名のため、`brew upgrade gcappy` の後に許可をもう一度求められることがあります。

## 注意

- 録音は参加者への告知と同意を得たうえで行ってください。
- マーカー（`cappy record` の Enter）は gcappy からは記録できません。
- `brew upgrade gcappy` の後にログイン時の起動が効かなくなった場合は、一度 `gcappy` で起動し、「ログイン時に起動」を入れ直してください。
